How these are counted

  • Source: the IN-CORE production request log (InfluxDB, measurement "auth"), one row per page or API request, snapshot taken Nov 5, 2026.
  • Signed-in users are distinct account names. Anonymous visits count toward requests and countries, not users.
  • Community requests are all requests except those from the three NCSA staff accounts, whose traffic is mostly automated.
  • Countries come from IP location. Most requests in the log carry no location, so country figures describe only the requests that do. Placeholder values ("-", "INVALID IP ADDRESS") are left out.
  • First-time users are accounts in this window with no request anywhere in the log before Aug 7, 2026.
  • JupyterHub's own usage gauges stopped reporting on Jan 16, 2025, so IN-CORE Lab use here comes from page requests only.
  • Scanner and bot probes (for example requests for wp-login.php) are in the raw log; none reached the tools listed here in this window.
